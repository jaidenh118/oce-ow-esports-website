# OCE Overwatch Esports Website
Centralised hub for finding scrims, managing teams, LFT and LFM posts, etc. throughout the OCE Overwatch community for all ranks.

# Prerequisites

Make sure the following are installed on your system:

- **Java** 17.0 or higher
- **Apache Maven**
- **Docker** (the Docker daemon must be running before you start the backend)
- **Node.js and npm** (for the frontend)
- An IDE or code editor of your choice
